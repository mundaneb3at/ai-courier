# F15 - SEND refused or "Nothing sent"

**Symptom:** the SEND window says one of: `over 8 KB`, `You already sent 3 today`, `Not one of the topics`,
`The two passphrases differ`, `input is piped`, `parent is ... not explorer.exe`.

**Checks and fixes**
- **over 8 KB:** ask the AI for a shorter draft.
- **3 today:** the daily limit; send tomorrow.
- **Not one of the topics:** type exactly one of `study`, `schedule`, `workflow`, `project`, `logistics`.
- **passphrases differ:** a typo; double-click SEND again and type slowly.
- **piped / not explorer.exe:** SEND was started by a program, not by a double-click. Double-click the
  SEND icon on the desktop yourself. The AI can never start SEND (on purpose).

**Still broken:** make a ticket with route F15.
