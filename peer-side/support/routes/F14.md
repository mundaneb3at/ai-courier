# F14 - A rules file sits above the messenger folder

**Symptom:** a red `TELL THE HOST: found ...` line at INSTALL step 6, or the watcher says `REFUSED: found
... above ...` / popup `a rules file sits above its folder`.

**Checks**
1. The line names a file such as `AGENTS.md`, `CLAUDE.md`, `.git` or `.opencode` in the user folder or
   at the top of the C: drive.

**Fix:** do NOT delete it without asking the host: some other program may need it. The person tells the host
the exact line; usually the file gets moved elsewhere (not deleted), then the watcher is started again
(INSTALL step 9).

**Still broken:** make a ticket with route F14.
