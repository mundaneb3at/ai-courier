# U1 - An update did not install

**Symptom:** `update.ps1` printed `REFUSED`, `STOPPED`, `ROLLED BACK`, `RESTORED` or `ROLLBACK MISMATCH`,
or the doctor says `update = INTERRUPTED`.

**Checks and fixes**
- **REFUSED ... signature / hash / version:** the update files are damaged, not from the host, or older
  than what is installed. Nothing was changed. Tell the host the REFUSED line.
- **REFUSED ... started by ...:** start it yourself from a PowerShell window you opened (never from
  the AI).
- **STOPPED ... files you changed:** the update would overwrite files changed on this computer. Nothing
  was changed. Put the list and `LOCAL-CHANGES.md` in a ticket so the host can decide.
- **ROLLED BACK:** the update installed but the safety test failed, so the old version was put back
  exactly. The messenger works as before. Tell the host.
- **INTERRUPTED / RESTORED:** an update stopped half-way (window closed, restart). Running the update
  again by hand puts the old version back first and says `RESTORED`; then run it once more to retry.
- **ROLLBACK MISMATCH:** the only bad case: don't use the messenger; text the host now.

**Still broken:** make a ticket with route U1. In "what we tried", say which word the last line started
with and copy the file ids it listed (like `r30 w04`). Don't paste the whole screen: it contains file
names, and the host's checker would hold the ticket back.
