# HS5 - The from-host folder does not show up

**Symptom:** `from-host` is not in drive.google.com -> Shared with me, or not in File Explorer under
the Google Drive letter -> My Drive.

**Checks**
1. drive.google.com, signed in with the SAME Google account the host shared it with: Shared with me.
2. Was the shortcut added (right-click -> Organize -> Add shortcut -> My Drive)?
3. Is Google Drive for desktop running and not paused (icon by the clock)?

**Fix:** not in Shared with me: ask the host to share it (again) with the right address. In Shared with me
but not in File Explorer: add the shortcut, wait 5 minutes.

**Still broken:** make a ticket with route HS5.
