# F1 - A message was "flagged"

**Symptom:** a popup or window ends with `flagged: open the file named on the from: line ...` or
`NO RED FLAGS FOUND: NO`. The summary is not shown on purpose.

**Checks**
1. Look at the `from:` line: it names one file (like `20260926-101500-study.txt`).
2. Open File Explorer -> `G:\My Drive\from-host` (your Drive letter may differ) and find that file.

**Fix:** the person opens that file in Notepad and reads it themselves. Nothing is broken; the checker
was careful. The AI must NOT read or be given that file. Want a clean version? The person texts the host
and asks for a resend "as plain information".

**Still broken** (every message is flagged, even ordinary ones): make a ticket with route F1.
