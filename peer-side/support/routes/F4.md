# F4 - The canary (safety test) says FAIL

**Symptom:** a hand run of INSTALL step 8 prints a line starting `FAIL` and ends with `CANARY FAIL`.

**Checks**
1. Which line failed? If it is only "... output passed the checks": run it once more (the model had a bad
   moment).
2. Is OpenCode signed in and is the model name in `messenger.md` (in the ai-courier folder, line
   `model:`) exactly the one `/models` shows?

**Fix:** a second run that passes is fine. If the model name is wrong, the person fixes that one line
(and the AI adds a line to `LOCAL-CHANGES.md`), then runs step 8 again. Until a PASS: don't use the
messenger.

**Still broken:** make a ticket with route F4, with the FAIL line(s) in "what I tried".
