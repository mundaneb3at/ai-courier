# F2 - "failed validation" or "messenger timed out"

**Symptom:** the view or popup says `[failed validation: ask for a resend ...]` or `messenger timed out:
ask for a resend`. The checker (a small AI with no tools) broke or took over 2 minutes on one message.

**Checks**
1. Did it happen once, or on every message? (Once = normal; the internet or the model was slow.)
2. Is OpenCode still signed in? In a PowerShell window: `opencode models` should list models.

**Fix:** once: the person reads the original file themselves (same as card F1) or texts the host for a
resend. Every time: sign OpenCode in again (`/connect` inside OpenCode), then run the canary by hand
(INSTALL step 8).

**Still broken:** make a ticket with route F2.
