# F6 - Nothing arrives (the watcher is not running)

**Symptom:** no messages for a while, or nothing since a restart; the minimized "AI courier
watcher" window is not in the taskbar.

**Checks**
1. Run `doctor.ps1` (ai-courier folder). The `watcher =` line says `running` or `not running`.
2. Is the Google Drive icon by the clock paused or signed out? (That is card F7.)

**Fix:** `not running`: the person pastes INSTALL step 9 into a PowerShell window they opened. The AI
cannot start the watcher for them (it refuses to start under an AI, on purpose). Running but still
nothing: ask the host whether they sent anything.

**Still broken:** make a ticket with route F6.
