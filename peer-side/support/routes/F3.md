# F3 - "the safety test failed after an update"

**Symptom:** popup `the safety test failed after an update; don't read messages, text the host a photo
of this window`. OpenCode updated itself, the watcher ran the safety test (canary) on its own, and it
failed. New messages are held (not lost).

**Checks**
1. Run the canary by hand: INSTALL step 8 (the person pastes it into a PowerShell window they opened).
2. Read the lines: which one says FAIL?

**Fix:** if the hand run says `CANARY PASS`, done: the held message opens by itself within a minute or
two. If only "output passed the checks" failed, run it once more. FAIL twice: go to card F4.

**Still broken:** make a ticket with route F3 (put the FAIL line in "what I tried").
