# F11 - The AI put a file in Google Drive by itself

**Symptom:** The host says they got an unsigned message from the person that they did not send, or the
person sees a file in their `from-<name>` Drive folder that SEND did not make.

**Checks**
1. Look in `G:\My Drive\from-<name>`: any file not made by SEND (SEND names files like
   `20260926-101500-study.txt`)?

**Fix:** nothing ran on the host's side (unsigned files are refused). The person deletes the stray file.
The AI must only write drafts into `outbox-staging` and never into any Drive folder
(`outbox-staging\_HOW-TO-DRAFT.md`). If it wrote there, add that rule to the chat and note it in
`LOCAL-CHANGES.md` if any setting was changed.

**Still broken** (it keeps happening): make a ticket with route F11.
